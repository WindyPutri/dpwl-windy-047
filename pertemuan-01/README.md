# Pertemuan 1
1. Kesinambungan PWD–DPW–DPWL
Jawaban:PWD–DPW–DPWL saling berhubungan dalam proses pengembangan aplikasi web. Materi dimulai dari dasar pembuatan web, dilanjutkan dengan pemrograman web yang terstruktur, dan pengembangan aplikasi web menggunakan konsep seperti MVC.
2. Perbedaan PHP Terstruktur dan MVC
Jawaban:PHP terstruktur memposisikan proses program dalam alur kode yang sederhana dan  MVC memiliki pembagian tugas yang lebih jelas
3. Fungsi Model, View, dan Controller
Jawaban:Model: mengolah data serta melakukan komunikasi dengan database.
View: menampilkan informasi kepada pengguna.
Controller: menerima input/request dan menentukan proses yang harus dilakukan.
4. Alur Request–Response MVC
Jawaban:User → Request → Controller → Model → Database → Model → Controller → View → Response → User
